# Solarcheck Lleida

Web de propuesta para Solarcheck Lleida, centro especializado en láminas de protección solar para vehículos y edificios.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

Para publicar la versión validada en GitHub Pages:

```bash
npm run deploy
```

El dominio de publicación permanente es `solarcheck.proposta.cat`.
